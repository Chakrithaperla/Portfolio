A futuristic, dark neon, modern, and fully responsive developer portfolio built for **Perla Chakritha** (Software Engineering Student | Full-Stack Developer).

---

## 📸 Profile Photo Setup

To customize or update your profile photo:
1. Place your photo file (e.g. `profile.jpg` or `profile.png`) in the `public/` directory.
2. In `src/data/portfolio.js`, confirm or update the path:
   ```javascript
   personal: {
     profileImage: "/profile.jpg", // or "/profile.png"
     ...
   }
   ```
If no image file is found, the application automatically displays an elegant high-tech monogram avatar without breaking.

- **About Section & 3 Core Engineering Pillars**: Full-Stack Development, Backend & APIs, Product Engineering.
- **Interactive Technical Arsenal**: Categorized glowing skill pills (Languages, Frontend, Backend, Databases, Authentication & Tools) with smooth hover micro-interactions.

- **Validated Contact Hub**: Direct email copy-to-clipboard, LinkedIn & GitHub quick links, interactive contact form with instant submission feedback and mailto fallback.
- **Interactive Resume Modal**: In-browser curriculum vitae viewer with print / save PDF capability.

- **Fully Responsive**: Optimized for Mobile (320px+), Tablets (768px+), Laptops (1024px+), and Ultrawide displays (1920px+).

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
